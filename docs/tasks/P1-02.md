# P1-02 — ach_core: identity, time, position, quantity

**Agent:** task-implementer · **Size:** S · **Depends on:** P1-01 · **Branch slug:** core-primitives · **Runs on:** either

## Goal
Define the primitive types every crate shares: typed identities, simulation time, fixed-point world positions, and integer quantities. These encode the determinism contract into the type system, so no later crate reaches for a float or a wall clock.

```rust
// ids.rs
/// Declares a typed u64 identifier.
#[macro_export]
macro_rules! define_id { ($(#[$m:meta])* $name:ident) => { /* derive Clone, Copy, Debug, PartialEq, Eq,
    PartialOrd, Ord, Hash, Serialize, Deserialize; #[serde(transparent)]; pub struct $name(pub u64);
    impl From<u64>; impl Display as "<name>#<n>" */ } }

/// Sequential allocator; part of simulation state.
#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct IdAllocator { next: u64 }
impl IdAllocator {
    pub fn new(first: u64) -> Self;
    pub fn alloc<T: From<u64>>(&mut self) -> T;   // = try_alloc().expect("invariant: u64 id space exhausted")
    pub fn try_alloc<T: From<u64>>(&mut self) -> Result<T, CoreError>; // returns next, then increments
}

// time.rs
/// Milliseconds since campaign epoch (Day 1, 00:00).
pub struct SimTime(pub i64);
/// Signed span in milliseconds.
pub struct SimDuration(pub i64);
impl SimDuration {
    pub const ZERO: Self;
    pub const fn from_secs(s: i64) -> Self; pub const fn from_mins(m: i64) -> Self;
    pub const fn from_hours(h: i64) -> Self; pub const fn from_days(d: i64) -> Self;
    pub const fn as_millis(self) -> i64;
    pub fn checked_add(self, o: Self) -> Option<Self>; pub fn checked_sub(self, o: Self) -> Option<Self>;
}
impl SimTime {
    pub const EPOCH: Self;                      // SimTime(0)
    pub fn day(self) -> i64;                    // 1-based; floor division (negative times → day ≤ 0)
    pub fn time_of_day(self) -> SimDuration;    // always in [0, 24h)
    pub fn at(day: i64, hour: i64, minute: i64) -> Self;
    pub fn checked_add(self, d: SimDuration) -> Option<Self>;
    pub fn since(self, earlier: SimTime) -> SimDuration;
}
// Display for SimTime: "D2 06:40" (seconds shown only if nonzero: "D2 06:40:15").
// FromStr for SimTime accepts the same format.
// All derive Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize.

// pos.rs
pub const CM_PER_M: i64 = 100;
/// Traversable layer; 0 = terrain surface (High-Level Design §4.1a).
pub struct LevelId(pub u16);
impl LevelId { pub const SURFACE: Self; }
/// Theater-frame position. x east, y north, centimeters.
pub struct WorldPos { pub x_cm: i64, pub y_cm: i64, pub level: LevelId }
impl WorldPos {
    pub const fn surface_m(x_m: i64, y_m: i64) -> Self;
    pub fn horizontal_distance_cm(&self, other: &WorldPos) -> i64;   // exact floor(sqrt(dx²+dy²)) via u128 isqrt
    pub fn lerp_permille(&self, other: &WorldPos, t_permille: i64) -> WorldPos; // t clamped to [0,1000]; round half toward -inf documented
}
/// Elevation in centimeters above datum.
pub struct ElevationCm(pub i32);

// qty.rs
/// Thousandths of a stock's base unit (1 L water ⇒ Milli(1000)).
pub struct Milli(pub i64);
/// Ratio in thousandths. 1000 = 100 %.
pub struct PerMille(pub i32);
impl Milli { pub fn checked_add(self, o: Milli) -> Option<Milli>; pub fn checked_sub(self, o: Milli) -> Option<Milli>;
             pub fn scale(self, p: PerMille) -> Milli; /* floor(self * p / 1000), exact via i128 */ }

// error.rs
#[derive(Debug, thiserror::Error)]
pub enum CoreError { #[error("identifier space exhausted")] IdExhausted, #[error("time overflow")] TimeOverflow, /* extend as needed in later tasks */ }
```

  - property: `time_of_day` is in [0, 24h) for any i64 in ±10¹⁵;
  - property: `horizontal_distance_cm` is symmetric, zero on identity, and satisfies the triangle inequality within 1 cm for coordinates in ±2·10⁸ cm (2,000 km);
  - known answers: distance (0,0)→(300,400) m = 50,000 cm; `Milli(1000).scale(PerMille(333)) == Milli(333)`.
