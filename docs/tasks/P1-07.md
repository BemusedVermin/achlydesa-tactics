# P1-07 — ach_world: navigation grid and pathfinding

**Agent:** task-implementer · **Size:** M · **Depends on:** P1-06 · **Branch slug:** world-pathing · **Runs on:** either

## Goal
Let columns cross the desert: fastest-time paths over real terrain for a movement profile, plus densified road routes. Speed follows Tobler's hiking function, which reproduces the High-Level Design's march tempo. It is precomputed into an integer table so the simulation never touches floating point.

## Specification

### Movement profile (content)
`tools/scripts/tobler_table.py` generates the `foot` speed table:
- Tobler v(s) = 6·exp(−3.5·|s + 0.05|) km/h, with s = slope as a fraction.
- Sample points at s = −600‰ … +600‰ in 20‰ steps (61 entries).
- Each value converted to mm/s and rounded to nearest. Flat (s = 0) must be 1399 mm/s.

```ron
// content/movement/profiles.ron
(
  profiles: {
    "foot": (
      speed_table: [(-600, 170), /* … */ (0, 1399), /* … */ (600, 146)], // (slope ‰, mm/s) — generated, do not hand-edit
      max_abs_slope_permille: 600,
      offroad_factor_permille: 900,
      road_factor_permille: { "intact": 1100, "worn": 1000, "broken": 850 },
    ),
  },
  generated_by: "tools/scripts/tobler_table.py",
)
```

(The endpoint values shown are illustrative; use the script's output.)

### Grid pathfinding
```rust
pub struct NavQuery<'a> { pub terrain: &'a Terrain, pub profile: &'a MovementProfile }
pub struct Path { pub points: Vec<WorldPos>, pub total_ms: i64 }
pub enum PathError { OutOfBounds, NoPath, SearchLimit }
impl<'a> NavQuery<'a> {
    pub fn find_path(&self, from: &WorldPos, to: &WorldPos, max_expansions: u32) -> Result<Path, PathError>;
}
```
- Cells are the 30 m base samples (heights from `base_height_cm`, not detail). 8-connected. Start and goal snap to the nearest sample. The returned path starts at `from` and ends at `to` exactly.
- Edge cost from sample A to neighbor B, in ms:
  - `d` = 3,000 cm orthogonal or 4,242 cm diagonal;
  - `slope = (h_B − h_A) * 1000 / d`;
  - `speed = base_speed(slope) * offroad_factor / 1000`;
  - `cost = d * 10 * 1000 / speed` (d in mm ⇒ ms);
  - impassable if the speed is None.
- Heuristic: octile distance in mm × 1000 / `max_speed_mm_s × offroad_factor / 1000`. This is admissible.
- Open set: `BinaryHeap<Reverse<(f, h, cell_index)>>`, giving deterministic tie-breaking. Closed set: `Vec<bool>` indexed by cell. Stop after `max_expansions` ⇒ `SearchLimit`.

## Acceptance
- `python3 tools/scripts/tobler_table.py` regenerates `profiles.ron`'s table byte-identically. Flat = 1399.
- Tests on synthetic terrain (`Terrain::from_fn`):
  - flat plane: the diagonal path cost equals the analytic octile time ±1 ms per step;
  - a 700‰ ridge wall with one 100 m gap: the path passes through the gap;
  - an uphill leg costs more than the same leg downhill at −50‰ (Tobler's asymmetry);
  - the same query twice gives an identical `Path`.
- `route_path`: no segment > 3,000 cm; endpoints equal the vertices; reversal yields the reversed point list.
- Timing: a 50 km query across a synthetic 96 × 24 km rough terrain finishes in < 2 s in release mode (report the measured time; not a CI test).
- `cargo xtask ci` passes.
