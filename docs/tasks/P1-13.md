# P1-13 — ach_text: grammar engine

**Agent:** task-implementer · **Size:** M · **Depends on:** P1-03 · **Branch slug:** text-engine · **Runs on:** either

## Goal
Reports are the player's main contact with the world: what their people saw, feared, and did. There will be thousands of them. Build a small, deterministic, voice-aware grammar engine, so that each named character sounds like themselves, lines rarely repeat, and every sentence is bound to real simulation facts. Later the same engine writes testimony, the Roll, and the archons' proclamations.

## Specification

### Grammar file (RON)
```ron
(
  symbols: {
    "march.departed": [
      (text: "{time:hm}. Moving. {persons} on the road, water at {water_l:L}.", weight: 1000, when: [], tags: ["terse"]),
      (text: "Out of #place.camp# at {time:hm}. #departed.detail#", weight: 800, when: ["day == 1"], tags: []),
    ],
  },
)
```
- **Template syntax:** `#symbol#` expands a symbol; `#symbol.cap#` capitalizes the first letter of the expansion; `{path}` or `{path:fmt}` inserts a binding. `##` gives a literal `#`; `{{` and `}}` give literal braces.
- **Conditions:** each string is `<path> <op> <literal>`, with op ∈ `< <= > >= == !=`, and literal an integer (may be negative) or a double-quoted string. All conditions must hold. They are parsed at load time; malformed ⇒ `TextError::BadCondition`.
- **Values:**
  ```rust
  pub enum Value { Int(i64), Text(String), DistanceM(i64), Time(SimTime), Duration(SimDuration), PerMille(i32), Milli(i64) }
  pub trait Bindings { fn get(&self, path: &str) -> Option<Value>; }
  pub struct MapBindings(pub BTreeMap<String, Value>);   // implements Bindings
  ```
  Comparisons: numeric values compare as i64; Text with `==`/`!=` only.
- **Formats** (integer arithmetic, round half up):

  | fmt | Input | Output example |
  |---|---|---|
  | `km1` | DistanceM(12_449) | `12.4 km` |
  | `km` | DistanceM(12_500) | `13 km` |
  | `m` | DistanceM(340) | `340 m` |
  | `hm` | Time | `06:40` |
  | `day` | Time | `Day 2` |
  | `dt` | Time | `D2 06:40` |
  | `dur` | Duration | `3 h 20 min` |
  | `pct` | PerMille(612) | `61%` |
  | `L` | Milli(340_400) | `340 L` |
  | `n` | Int(1412) | `1,412` |
  | `words` | Int 0–20 | `twelve` (else digits) |

  With no fmt, each Value has a sensible default. A wrong type for a fmt ⇒ `TextError::FormatMismatch`.

### Voices
```ron
( voices: { "ione": (tags: { "terse": 2000, "dry": 1500, "formal": 500 }, avoid_repeat: 3) } )
```
```rust
pub struct VoiceProfile { pub id: String, pub tags: BTreeMap<String, u32>, pub avoid_repeat: u8 }
pub struct VoiceSet { pub voices: BTreeMap<String, VoiceProfile> }
```
Effective weight of an alternative = `weight × Π_{tag ∈ alt.tags} voice.tags.get(tag).unwrap_or(1000) / 1000`, computed in u64 with division after each factor. Minimum effective weight 1 if the base weight > 0.

### Expansion
```rust
pub struct Grammar { /* parsed */ }
impl Grammar { pub fn from_ron(src: &str) -> Result<Grammar, TextError>; pub fn merge(&mut self, other: Grammar) -> Result<(), TextError>; /* duplicate symbol ⇒ Err */ }

#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct ExpansionHistory { recent: BTreeMap<(String, String), VecDeque<u16>> } // (speaker, symbol) → recent alt indices

pub struct Expander<'g> { pub grammar: &'g Grammar, pub history: &'g mut ExpansionHistory }
impl<'g> Expander<'g> {
    pub fn expand(&mut self, symbol: &str, speaker: &VoiceProfile, bindings: &dyn Bindings, rng: &mut RngCursor)
        -> Result<String, TextError>;
}
```
Selection for each symbol occurrence:
1. Candidates are the alternatives whose conditions all hold.
2. Drop those in the speaker's recent history for this symbol, unless that would leave none.
3. `choose_weighted` with the effective weights (one RNG draw per choice).
4. Record the chosen index in history (capped at `avoid_repeat`).
5. Recurse into nested symbols.

Limits: depth 16 ⇒ `TooDeep`; output > 2,000 chars ⇒ `TooLong`; no candidates ⇒ `NoAlternative { symbol }`.

### Lint
```rust
pub struct BindingSchema { pub roots: BTreeMap<String, BTreeSet<String>> } // root symbol → bindings available
pub enum LintIssue { UnknownSymbol{..}, UnknownBinding{..}, NoUnconditionalFallback{symbol}, UnreachableSymbol{symbol}, BadFormat{..}, UnknownVoiceTag{..} }
pub fn lint(grammar: &Grammar, voices: &VoiceSet, schema: &BindingSchema) -> Vec<LintIssue>;
```
- Nested symbols inherit their root's binding set; a symbol reachable from several roots must be valid for each.
- Every symbol must have at least one alternative with no conditions.
- Tags used in grammars but absent from every voice produce warnings (the `UnknownVoiceTag` variant); all other issues are errors.

## Acceptance
- Unit tests for every format row above (known answers), for condition parsing and evaluation, and for escapes.
- Determinism: the same grammar, voice, bindings, and cursor produce the same string; different seeds usually differ (test over 100 seeds: ≥ 5 distinct outputs for a symbol with 6 alternatives).
- `avoid_repeat = 3` with 4 alternatives: no alternative repeats within any window of 4 consecutive expansions (property).
- Lint catches each issue kind in a crafted bad grammar.
- `insta` snapshot of 20 expansions of a small sample grammar.
- `cargo xtask ci` passes.
