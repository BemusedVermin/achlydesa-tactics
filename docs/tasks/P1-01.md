## Specification

### Workspace
- `resolver = "3"`, `edition = "2024"`, members `crates/*`, `xtask`, `spikes/*`. If Cargo rejects the `spikes/*` glob while `spikes/` is empty, omit it and say so in the report; P1-S1 adds it.
- `rust-toolchain.toml`: pin the **current stable** version exactly (e.g. `channel = "1.xx.0"`) with components `rustfmt` and `clippy`. Record the version in the report. A pinned compiler is part of the determinism contract.
- `[workspace.lints.rust]`: `unsafe_code = "forbid"`, `missing_docs = "warn"`.
- `[workspace.lints.clippy]`: `unwrap_used = "warn"`, `dbg_macro = "warn"`, `todo = "warn"`.
- Every crate: `[lints] workspace = true`.

### Crate roots
Each simulation crate's `lib.rs` begins:

```rust
//! <one-line purpose>. See Execution Plan §4.1.
#![forbid(unsafe_code)]
#![deny(clippy::float_arithmetic)]
```

Simulation crates: all `ach_*` except `ach_tools`. The stub crates (`ach_know`, `ach_orders`, `ach_ai`, `ach_combat`, `ach_anomaly`, `ach_narrative`, `ach_affect`, `ach_plate`) contain only that header and a doc paragraph naming the phase that fills them. They have **no dependencies yet**.

`ach_tools` root: `#![forbid(unsafe_code)]` and `#![allow(clippy::disallowed_types)]`. Its `main.rs` uses `clap` with a placeholder `ach --version`.

Note that `ach_sim` may **not** depend on `ach_text`. Reports are produced by tools from journals.

### `xtask`
Subcommands:
- `check-deps`: runs `cargo metadata --format-version 1`, and for every workspace package checks each normal and dev dependency against the table. Workspace-internal deps go under `[internal]`; other deps under `[external]`, where `spikes/*` matches any package in `spikes/`. Packages under `spikes/` may depend on any workspace crate (their external deps are still checked). No non-spike workspace crate may depend on a `spikes/*` package. On failure, print each violating edge and exit 1.
- `ci`: runs in order, stopping at the first failure:
  1. `cargo fmt --all -- --check`
  2. `cargo clippy --workspace --all-targets -- -D warnings`
  3. `cargo test --workspace`
  4. `check-deps`
  5. if `content/text/` exists, `cargo run -q -p ach_tools -- text lint`

## Acceptance
- `cargo xtask ci` passes on the clean workspace.
- Add a temporary `HashMap` use in `ach_core` → clippy fails. Revert. (Describe it in the report; do not commit it.)
- Add a temporary `ach_sim` → `ach_text` dependency → `cargo xtask check-deps` fails naming that edge. Revert.
- The PR's `ci` check is green.
- Add a temporary `let x = 1.0_f64 * 2.0;` in `ach_world` → clippy fails. Revert.

## Out of scope
Any real code in the crates. CI workflows: `.github/workflows/ci.yml` already exists and starts running `cargo xtask ci` as soon as `Cargo.toml` exists.
