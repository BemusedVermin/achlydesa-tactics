# P0-04 — Archon size canon

**Agent:** canon-editor · **Size:** M · **Depends on:** H-1 · **Branch slug:** size-canon · **Runs on:** either

## Goal
Awe needs numbers. Fix the physical dimensions of the theater archons so angular size, footprints, first-sighting distances, and later rendering are computed rather than staged. The same data file drives the atlas footprint, the glyph, and the horizon plate in later phases.

## Read first
- World Bible §Visual grammar, §Distribution across the desert, and the entries for the Heliarch, Mneme, Pylaios, Anodyne, Strategos, Autophagos, and Aletheia.
- Execution Plan §2.2 (the proposed table).
- Field Atlas §6.2.

## Deliverables
- `docs/canon/ARCHON_SIZE_CANON.md`
- `content/archons/size_canon.ron`
- `tools/scripts/angular_size.py` (computes every derived number in the document from the RON file)

## Specification

### Data (`content/archons/size_canon.ron`)
One entry per archon. All lengths are integer meters, speeds integer m/h:

```ron
(
  status: "PROPOSED",
  archons: [
    (
      id: "heliarch",
      name: "The Heliarch of the Second Sky",
      body: (length_m: 2400, width_m: 900, height_m: 500),
      altitude_m: Some((min: 1000, cruise: 3000, max: 6000)),   // None for ground bodies
      footprint_m: None,                                         // ground contact, or None if airborne
      speed_m_per_h: (typical: 20000, max: 60000),
      haze_visibility_km: 120,       // max sighting range in clear desert air; tunable
      scale_contrast: None,          // e.g. Strategos's 40 m brain inside 6 km of wings
      notes: "Belly toward the sun; oil curtains below. World Bible §The Heliarch of the Second Sky",
    ),
    // …
  ],
)
```

Required archons: heliarch, autophagos, anodyne, strategos, pylaios, mneme, aletheia. Start from Execution Plan §2.2. Where the World Bible gives a scale cue ("mountain-sized", "higher than a city wall", "four stories"), your numbers must honor it; cite it. Mneme is a river: give width, and length as a range.

### Derived numbers (script output, pasted into the markdown)
For each archon:
- angular size (degrees, one decimal) at 2, 5, 10, 20, and 40 km, and overhead where applicable, using θ = 2·atan(s / 2d) with s the largest visible dimension, and d the straight-line distance including altitude;
- geometric first-sighting distance d_h ≈ 3.57·(√h_obs + √h_target) km, with h in meters and h_obs = 2 m;
- effective first-sighting distance = min(d_h, haze_visibility_km);
- atlas footprint in chunk units (1 chunk = 1.92 km; see P1-06), to show how far it runs off a sheet.

### Document (`docs/canon/ARCHON_SIZE_CANON.md`)
`Status: PROPOSED`. For each archon: a one-line image in plain words; the numbers; the canon citations; and one sentence on the awe beat the scale enables — the most dramatic distance at which a squad would see it, and the angular size there. Close with a "scale contrasts" section: Strategos's small brain, and the Receiver as a human-sized presence (Campaign Bible §10).

## Acceptance
- `python3 tools/scripts/angular_size.py content/archons/size_canon.ron` runs and prints tables identical to those in the markdown.
- Execution Plan §2.2 angles are reproduced within ±1° where you kept its numbers. Any changed number is justified in one sentence.
- Every scale cue in the World Bible entries you read is either honored or flagged under Open questions.
