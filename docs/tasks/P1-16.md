# P1-16 — TUI trace viewer

**Agent:** task-implementer · **Size:** M · **Depends on:** P1-15 · **Branch slug:** trace-viewer · **Runs on:** local

## Goal
A terminal window onto a run: the map of the strip, the caravan's exact position at any moment, its stocks, and the words its people wrote. It is a debugging tool first, and the first place you can scrub back and watch a march happen, which is the seed of the execution replay (Execution Plan §2.6).

## Specification

### Command
`ach view <run-dir>` loads the scenario (path recorded in `summary.ron`), `journal.bin`, the terrain, and the report lines.

### Exact positions
- On open, rebuild the `Sim` from the scenario and build checkpoints: a snapshot in memory every 6 simulated hours.
- To show time t: clone the nearest checkpoint ≤ t, `run_until(t)` into a discarding journal writer, and call `column_position_at`. There is no interpolation between journal entries.

### Layout (≥ 100 × 30 terminal)

| Area | Contents |
|---|---|
| Left 60% — map | Strip hillshade as shade characters ` .:-=+*#%@` by luminance; `dry_meridian` and other routes as `·`; sites as their first letter, capitalized; the column as `@` in friendly style; a scale line (`|——| 5 km`). |
| Right 40% — timeline | Event list: `D2 06:40  SiteReached  roadside_terminal`. Events with report lines are marked `✎`. |
| Bottom — panels | Stocks for the selected time (water, food as bars with numbers); the report line of the selected event, if any, with speaker; current activity. |

### Keys
- `↑/↓` or `k/j`: select event.
- `[` / `]`: previous/next day.
- `←/→`: scrub ±10 minutes.
- `Space`: autoplay (1 sim hour per 100 ms).
- `+/-`: map zoom (1×, 2×, 4× around the column).
- `q`: quit.
