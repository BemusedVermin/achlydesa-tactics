**Agent:** canon-editor · **Size:** M · **Depends on:** H-1 · **Branch slug:** conflict-ledger · **Runs on:** either

## Goal
The six design documents were written at different times and disagree. Agents building the game need one answer per question. Produce a ledger of every material contradiction and a proposed decision record for each, so Liam can settle them in one sitting (H-2).

## Specification

### Ledger format (`docs/canon/CONFLICTS.md`)
Header line `Status: PROPOSED`. Then one section per conflict:

```
## C-NN — <short title>
**Severity:** blocking (a Phase 0–1 task depends on it) | later (Phase 2+) | cosmetic
**Sources:**
- <file §section>: <paraphrase or ≤25-word quote>
- <file §section>: <…>
**Proposed resolution:** <one or two sentences>
**ADR:** ADR-NNNN (or "none — cosmetic, fixed in P0-02")
```

### Finding further conflicts
Search all design docs for each of: faction and state names; archon names paired with "present", "theater", "region"; numbers (squad sizes, theater size, grid spacing, years, `A238`, "twenty years"); "camera", "portrait", "tutorial", "research", "manufacture"; the names of the named characters. Record only **material** contradictions — two statements that cannot both be true and that would lead two engineers to build different things. Ignore different phrasings of the same idea.

### ADR format
Use `docs/decisions/ADR-TEMPLATE.md`. Status `Proposed`. Options: at least two, including the recommended one. Consequences: list the documents P0-02 must edit and any task specs affected.

## Acceptance
- C-01…C-08 present with at least two sources each.
- Every `file §section` citation resolves: for each, `grep -n` finds the heading text in that file. List the grep commands and results in the report.
- Every blocking or later conflict has exactly one ADR; every ADR is referenced by exactly one conflict.
- No ADR is marked Accepted.

## Out of scope
Editing any design document (that is P0-02). Inventing new factions or lore to resolve a conflict: resolve toward existing canon.

## Review focus (Liam)
The Decision section of each ADR. This is the one sitting where you set the game's canon.
