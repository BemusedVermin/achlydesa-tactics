## Specification
```rust
ach_core::define_id!(CharacterId);

#[derive(Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
pub enum Role { EscortCaptain, RecoveryChief, Orderly, TransportLeader, GuardTrainee, ArchiveKeeper, Guard, Passenger, Other(String) }

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Character { pub id: CharacterId, pub key: String, pub name: String, pub age: u16, pub role: Role, pub voice: String }

#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Roster { by_id: BTreeMap<CharacterId, Character>, by_key: BTreeMap<String, CharacterId> }
impl Roster {
    /// Loads a content file and assigns ids with the allocator, in file order.
    pub fn load(path: &Path, ids: &mut IdAllocator) -> Result<Self, PeopleError>;
    pub fn get(&self, id: CharacterId) -> Option<&Character>;
    pub fn by_key(&self, key: &str) -> Option<&Character>;
    pub fn iter(&self) -> impl Iterator<Item = &Character>;  // id order
}
```

Content file entries: `(key: "ione_var", name: "Ione Var", age: 41, role: EscortCaptain, voice: "ione")`, and likewise for the other five, with ages and roles from Campaign Bible §6. Duplicate keys ⇒ `PeopleError::DuplicateKey`.
