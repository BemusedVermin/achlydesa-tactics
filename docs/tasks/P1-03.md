# P1-03 — ach_core: keyed random streams

**Agent:** task-implementer · **Size:** S · **Depends on:** P1-02 · **Branch slug:** core-rng · **Runs on:** either

## Goal
All randomness in Achlydesa comes from a counter-based, keyed generator. The same (seed, domain, subject, counter) always yields the same number, regardless of evaluation order. This is what lets distant quiet simulation, replays, and save/load agree to the byte.

## Specification

```rust
/// Campaign seed.
pub struct Seed(pub u64);                          // derive Copy, Eq, Ord, Serialize…

/// Stable domain tags. NEVER renumber; only append.
#[repr(u32)]
#[non_exhaustive]
pub enum Domain { Test = 0, Terrain = 1, Movement = 2, Logistics = 3, Text = 4, Portrait = 5, Weather = 6 }

pub struct StreamKey { pub domain: Domain, pub subject: u64 }

/// SplitMix64 finalizer. Frozen.
pub const fn mix64(z: u64) -> u64 {
    let z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    let z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^ (z >> 31)
}

/// Frozen derivation:
/// h = mix64(seed ^ 0x9E37_79B9_7F4A_7C15); h = mix64(h ^ domain as u64); h = mix64(h ^ subject); h = mix64(h ^ counter)
pub fn draw_u64(seed: Seed, key: StreamKey, counter: u64) -> u64;

/// Uniform in [0, bound) via 128-bit multiply-high (bias ≤ bound / 2^64; documented, accepted). bound == 0 ⇒ 0.
pub fn draw_below(seed: Seed, key: StreamKey, counter: u64, bound: u64) -> u64;

/// Uniform per-mille in [0, 1000).
pub fn draw_permille(seed: Seed, key: StreamKey, counter: u64) -> PerMille;

/// Weighted choice over integer weights; returns index, or None if all weights are 0.
pub fn choose_weighted(seed: Seed, key: StreamKey, counter: u64, weights: &[u32]) -> Option<usize>;

/// Stateful convenience cursor (serializable). Each call uses the current counter, then increments.
pub struct RngCursor { pub seed: Seed, pub key: StreamKey, pub counter: u64 }
impl RngCursor { pub fn new(seed: Seed, key: StreamKey, start: u64) -> Self; pub fn next_u64(&mut self) -> u64;
                 pub fn below(&mut self, bound: u64) -> u64; pub fn permille(&mut self) -> PerMille;
                 pub fn choose_weighted(&mut self, weights: &[u32]) -> Option<usize>; }

// hash.rs
/// FNV-1a 64-bit over bytes. Frozen: offset 0xcbf29ce484222325, prime 0x100000001b3.
pub fn fnv1a64(bytes: &[u8]) -> u64;
```

## Acceptance
- Known-answer tests: compute `draw_u64` for (seed 0, Test, 0, 0), (seed 1, Terrain, 42, 7), (seed u64::MAX, Text, u64::MAX, u64::MAX). Freeze the outputs as constants in the test with a comment "frozen P1-03; changing these breaks every save". Same for `fnv1a64(b"")` = 0xcbf29ce484222325 and `fnv1a64(b"a")` = 0xaf63dc4c8601ec8c.
- Property: `draw_below(…, bound)` < bound for bound in 1..=u64::MAX sampled.
- Distribution sanity: 100,000 draws of `draw_below(…, 10)` over consecutive counters put each bucket within ±5 % of 10,000.
- Property: `choose_weighted` never returns an index whose weight is 0.
- Property: `RngCursor` sequence equals direct `draw_u64` calls with counters start, start+1, …
- `cargo xtask ci` passes.
