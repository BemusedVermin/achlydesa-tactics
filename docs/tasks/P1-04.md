## Specification

### Common header (little-endian)
| Bytes | Field |
|---|---|
| 4 | magic: `ACHJ` journal · `ACHS` snapshot · `ACHT` terrain chunk (used by P1-06) |
| 2 | `format_version: u16` = 1 |
| 4 | `schema_version: u32` — supplied by the caller (the simulation's schema) |
| 8 | `seed: u64` |
| 2 | `label_len: u16`, then `label` UTF-8 bytes (scenario or content id) |

```rust
pub struct FileHeader { pub magic: [u8; 4], pub format_version: u16, pub schema_version: u32, pub seed: Seed, pub label: String }
pub const MAGIC_JOURNAL: [u8; 4] = *b"ACHJ"; pub const MAGIC_SNAPSHOT: [u8; 4] = *b"ACHS"; pub const MAGIC_TERRAIN: [u8; 4] = *b"ACHT";
pub fn write_header<W: Write>(w: &mut W, h: &FileHeader) -> Result<(), CoreError>;
pub fn read_header<R: Read>(r: &mut R, expected_magic: [u8; 4]) -> Result<FileHeader, CoreError>;
```

### Journal
After the header, a sequence of frames: `u32 LE length` + postcard bytes of `JournalEntry<E>`.

```rust
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct JournalEntry<E> { pub seq: u64, pub time: SimTime, pub event: E }

pub struct JournalWriter<W: Write> { /* next_seq, last_time, running fnv1a64 over frame bytes */ }
impl<W: Write> JournalWriter<W> {
    pub fn create(w: W, header: FileHeader) -> Result<Self, CoreError>;            // writes header
    pub fn resume(w: W, next_seq: u64, last_time: SimTime, fingerprint: u64) -> Self; // append after load
    pub fn append<E: Serialize>(&mut self, time: SimTime, event: &E) -> Result<u64, CoreError>; // returns seq
    pub fn fingerprint(&self) -> u64;   // fnv1a64 chained over every frame's bytes so far
    pub fn next_seq(&self) -> u64;
    pub fn into_inner(self) -> W;
}
pub struct JournalReader<R: Read, E> { /* … */ }
impl<R: Read, E: DeserializeOwned> JournalReader<R, E> {
    pub fn open(r: R) -> Result<(FileHeader, Self), CoreError>;
}
impl<R: Read, E: DeserializeOwned> Iterator for JournalReader<R, E> { type Item = Result<JournalEntry<E>, CoreError>; }
```

Rules:
- `append` fails with `CoreError::TimeWentBackwards` if `time < last_time`. Equal times are allowed.
- Fingerprint chaining: `fp = fnv1a64(fp.to_le_bytes() ++ frame_bytes)`, starting from `fnv1a64(header_bytes)`.
- A truncated final frame yields one `Err(CoreError::TruncatedFrame)` then iteration ends. Maximum frame size is 16 MiB (`CoreError::FrameTooLarge`).

### Snapshot
Header followed by one frame containing postcard bytes of the caller's state `T: Serialize`.

```rust
pub fn write_snapshot<W: Write, T: Serialize>(w: &mut W, header: &FileHeader, state: &T) -> Result<(), CoreError>;
pub fn read_snapshot<R: Read, T: DeserializeOwned>(r: &mut R) -> Result<(FileHeader, T), CoreError>;
```

## Acceptance
- Round trip: write 10,000 entries of a test enum (with nested strings, `WorldPos`, `SimTime`), read them back, compare equal.
- Byte determinism: writing the same entries twice produces identical bytes and identical fingerprints.
- Property: for random entry sequences, the fingerprint after `resume` + append equals the fingerprint of one uninterrupted write.
- Truncation: cutting the file mid-frame yields exactly one `TruncatedFrame` error.
- Wrong magic ⇒ `CoreError::BadMagic`; `format_version` ≠ 1 ⇒ `CoreError::UnsupportedFormat`.
- `cargo xtask ci` passes.
