# H-1 — Repository, GitHub, and agent setup

**Agent:** Liam · **Size:** M · **Depends on:** — · **Branch slug:** — · **Runs on:** human

## Goal
Stand up the repository, the bot identity, the Project board, and the agent workflows, so that every later task can be run locally with `/task <ID>` or on GitHub by adding the `agent:run` label.

## Steps

### 1. Repository
1. Unzip the kit into an empty directory; that directory becomes the repo root.
2. Create the GitHub repo and push the kit in one step (replace `<owner>` with your username or your organization):
   ```bash
   git init -b main
   git add -A
   git commit -m "Kit"
   gh repo create <owner>/achlydesa --private --source=. --remote=origin --push
   ```
   Or, if you created the repo in the GitHub web UI, replace the last line with:
   ```bash
   git remote add origin git@github.com:<owner>/achlydesa.git   # or https://github.com/<owner>/achlydesa.git
   git push -u origin main
   ```
3. Replace `@YOUR-GITHUB-USERNAME` in `.github/CODEOWNERS` with your username, then commit and push.

### 2. Bot identity (recommended)
Agent pull requests should be authored by a machine account, not by you. GitHub doesn't let you approve or request changes on your own PR, and those review states are what drive revision mode.
1. Create a machine GitHub account (e.g. `achlydesa-bot`). Add it as a collaborator with **Write** access to the repo, and as a collaborator on the Project (step 4) with **Write**.
2. As the bot, create a **classic** personal access token with scopes `repo`, `workflow`, `project`.
3. Store it in the repo as secret `ACHLYDESA_BOT_TOKEN`. Locally, keep it in a file only you can read (e.g. `~/.config/achlydesa/bot-token`, mode 600).

Without a bot, everything still works: agents open PRs as you, and you signal revisions with the `changes-requested` label instead of a "Request changes" review.

### 3. Claude on GitHub
1. In Claude Code in the repo, run `/install-github-app` and follow it to install the Claude GitHub App. Choose either an API key (`ANTHROPIC_API_KEY`) or your subscription (`CLAUDE_CODE_OAUTH_TOKEN`, from `claude setup-token`). The workflows use `CLAUDE_CODE_OAUTH_TOKEN`; switch the input name in `.github/workflows/agent-*.yml` and `claude.yml` if you chose an API key.
2. If the installer adds its own `claude.yml`, keep the kit's version (it is restricted to collaborators and uses Sonnet).

### 4. Project board and issues
```bash
gh auth login                       # as yourself
python3 tools/scripts/gh_task.py bootstrap --owner <you-or-org> --reviewer <your-login> --dry-run   # read the plan
python3 tools/scripts/gh_task.py bootstrap --owner <you-or-org> --reviewer <your-login>
python3 tools/scripts/gh_task.py check
git add .github/project.json && git commit -m "Project config" && git push
```
The bootstrap:
- creates the labels and the Project ("Achlydesa"), and links it to the repo;
- adds the fields Task ID, Phase, Agent, Size, and Runs on;
- creates one issue per spec in `docs/tasks/`, with dependencies as issue links, and adds every issue to the board.

Then, in the Project's web settings:
1. **Status field:** make its options exactly `Todo`, `In Progress`, `Awaiting review`, `Changes requested`, `Done`. The CLI cannot add options, so `check` tells you what's missing.
2. **Workflows:** enable *Item closed → Done* and *Pull request merged → Done*.
3. **Views:** add a Table view grouped by Phase, showing Task ID, Status, Agent, Size, and Runs on.

### 5. Branch protection on `main`
- Require a pull request before merging, with **1 approval** and **Review from Code Owners** (works solo because the bot authors PRs).
- Require the status check **ci** (from the CI workflow) to pass.
- Do not allow bypass, except for yourself if you want an escape hatch.

### 6. Local toolchain
- Rust via rustup (the pinned version installs automatically on first `cargo` run after P1-01).
- Python 3 (plus `pip install -r tools/scripts/requirements.txt` after P0-05).
- The GitHub CLI `gh`, and Claude Code.
- Launch Claude Code with the bot token so local agent PRs are bot-authored:
  ```bash
  GH_TOKEN="$(cat ~/.config/achlydesa/bot-token)" claude
  ```
  Then run `/model sonnet`.

## Done when
`python3 tools/scripts/gh_task.py check` passes. Every task appears on the board as Todo. Adding `agent:run` to a throwaway test issue starts the **Agent task** workflow, which comments that the ID is unknown, then you close the issue. Close this issue.
