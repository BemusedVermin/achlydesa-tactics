# P1-08 — ach_sched: event scheduler

**Agent:** task-implementer · **Size:** S · **Depends on:** P1-02 · **Branch slug:** sched · **Runs on:** either

## Goal
The single authoritative ordering of everything that happens in Achlydesa. Event-driven WEGO lets days pass in one commit and seconds pass in a firefight. Both rest on a deterministic, serializable, cancellable queue.

## Specification
```rust
/// Total order: time, then phase (lower first), then insertion sequence.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
pub struct EventKey { pub time: SimTime, pub phase: u8, pub seq: u64 }
pub type EventHandle = EventKey;

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Scheduler<E> { queue: BTreeMap<EventKey, E>, next_seq: u64, now: SimTime }

impl<E> Scheduler<E> {
    pub fn new(start: SimTime) -> Self;
    pub fn now(&self) -> SimTime;
    pub fn len(&self) -> usize; pub fn is_empty(&self) -> bool;
    /// Err(SchedError::InPast) if at < now.
    pub fn schedule(&mut self, at: SimTime, phase: u8, event: E) -> Result<EventHandle, SchedError>;
    pub fn cancel(&mut self, handle: EventHandle) -> Option<E>;
    pub fn peek(&self) -> Option<(&EventKey, &E)>;
    /// Pops the earliest event and sets now = its time.
    pub fn pop_next(&mut self) -> Option<(EventKey, E)>;
    /// Pops only if the earliest event's time <= limit.
    pub fn pop_until(&mut self, limit: SimTime) -> Option<(EventKey, E)>;
    /// Moves now forward with no event. Err(SchedError::WouldSkipEvent) if an event is pending before t; Err(InPast) if t < now.
    pub fn advance_to(&mut self, t: SimTime) -> Result<(), SchedError>;
    /// Iterator over pending events in order (for debugging views).
    pub fn iter(&self) -> impl Iterator<Item = (&EventKey, &E)>;
}
```
Phase constants live with the caller (`ach_sim`). Document that a lower phase runs first at equal times.

## Acceptance
- Property: popping all events yields keys in strictly increasing order for random schedules with equal times and phases.
- Property: `cancel` of a random subset removes exactly those events; the remaining order is unchanged.
- Property: serialize (postcard via `ach_core` snapshot helpers) → deserialize → continue popping gives the same sequence as without the round trip.
- `advance_to` refuses to skip a pending event.
- `cargo xtask ci` passes.
