# P1-06 — ach_world: terrain chunks and height queries

**Agent:** task-implementer · **Size:** M · **Depends on:** P1-03, P1-04 · **Branch slug:** world-terrain · **Runs on:** either

## Goal
Represent the theater's ground: chunked integer heightfields sampled from real elevation data, plus deterministic procedural detail below the source resolution. Every later system — movement, sight lines, the atlas's contours, the horizon plate that shows a whale over the ridge — asks this crate "how high is the ground here?"

### Algorithms (integer only; floor = arithmetic shift or `div_euclid`)
- **Chunk files:** `P1-04` header with `MAGIC_TERRAIN`, schema 1, seed = `detail.seed`, label = `name`; then one postcard frame of `HeightChunk`. Manifest as pretty RON.
- **Base bilinear:** locate the chunk, the cell (col,row), and fractions fx, fy in Q16 (0..65536) from the in-cell offset: `f = (offset_cm << 16) / BASE_SPACING_CM`. Result `= (h00*(1-fx)(1-fy) + h10*fx(1-fy) + h01*(1-fx)fy + h11*fx*fy) >> 32` computed in i64 (i128 if needed). Positions exactly on the max edge are inside.
- **Detail:** value noise summed over `octaves`. Octave k has wavelength `base_wavelength_m >> k` and amplitude `amplitude_cm >> k`. Lattice value at integer lattice (i, j): `draw_below(Seed(detail.seed), StreamKey{domain: Terrain, subject: mix64(mix64(mix64(k) ^ i as u64) ^ j as u64)}, 0, 2*amp+1) as i64 - amp`. Interpolate with smoothstep weights `s = f*f*(3*65536 - 2*f) >> 32` (Q16), bilinear over the four lattice corners.
- `height_cm = base + detail`.
- **Slope** (a→b) = `(h_b − h_a) * 1000 / horizontal_distance_cm`, truncating toward zero; distance 0 ⇒ `Some(0)`.
- **Gradient** at p: central differences at ±1,500 cm in x and y using `height_cm`; `gx = (h(x+) − h(x−)) * 1000 / 3000`, likewise gy; magnitude = isqrt(gx² + gy²).
- **Surface class** thresholds (‰): Flat < 30 ≤ Gentle < 120 ≤ Steep < 400 ≤ Cliff.

## Acceptance
- `cargo test -p ach_world` including:
  - `from_fn` with a plane `h = 2x/1000 + 5y/1000` (cm) reproduces exact heights at samples, and bilinear heights within 1 cm anywhere;
  - base heights are continuous across chunk edges (property: |h(x) − h(x+1 cm)| ≤ 2 cm on a smooth synthetic surface);
  - detail is deterministic, bounded by Σ amp_k, and different seeds give different fields;
  - known-answer detail values at three positions, frozen;
  - save → load round trip is byte-identical (re-save compares equal);
  - gradient of the plane ≈ isqrt(2² + 5²) = 5‰ (±1).
- `cargo xtask ci` passes.
