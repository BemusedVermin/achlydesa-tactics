## Specification

### Commands
```
ach run <scenario.ron> [--until "D5 00:00"] [--out runs/<scenario-id>] [--snapshot-at "D2 12:00"]
ach journal dump <journal.bin> [--from SEQ] [--to SEQ]      # RON, one entry per line
ach report <run-dir>                                         # re-render report.md from journal.bin
```

`ach run` writes into the output directory (created if missing, overwritten if present):
- `journal.bin`;
- `journal.ron` (the dump);
- `report.md`;
- `summary.ron` (`RunSummary`, plus the scenario file path, final stocks per column, and the scenario content fingerprint);
- `snapshot_end.bin`;
- `snapshot_<time>.bin` if `--snapshot-at` is given.

Print a one-screen summary: arrival times, distance, water remaining, event count, fingerprint.

### Scenario
- Column **"Red Ledger caravan"**. Leader `ione_var`; reporters `ione_var`, `petra_oss`, `eren_tal`.
- Persons: 84 (PROPOSED; the Campaign Bible gives no number — note that in a comment).
- Profile `foot`, posture 620 (guarded).
- Windows 04:30–10:30 and 15:30–19:30; cycles 50/10.
- Legs: `FollowRoute dry_meridian` to `inspection_station`, then to `roadside_terminal`, then `FollowRoute reedbank_spur` to `reedbank`. Adjust to the actual route topology from P0-06.
- Start D1 04:30; end D6 00:00.
- **Water:** choose the initial amount so that the 250‰ threshold fires on day 3 and the water does **not** run out before Reedbank. Show the arithmetic in a comment.
- Food: 5 days' rations.
